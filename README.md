# 단수달 🦦

수달과 함께 떠요!
뜨개인 여러분, 한 단 한 단 종이에 체크하려니 번거롭지 않으셨나요? 단수달과 함께 뜨면 절대 헷갈리지 않아요.

**🧶 [지금 써보기 → ssurxiv.github.io/dansudal](https://ssurxiv.github.io/dansudal/)**

## ✨ 뭘 할 수 있나요?

- **단수 세기**: "한 단 떴어요"를 누르면(또는 스페이스바) 단수가 오르고,
  캐릭터의 뜨개감도 목표 대비 진행률만큼 자랍니다.
- **목표 단수**: 목표를 직접 입력해두면 진행률과 남은 단수를 한눈에
  볼 수 있어요.
- **되돌리기**: 실수했으면 "한 단 풀기"(백스페이스)로 방금 뜬 단을
  되돌릴 수 있습니다. 풀어낸 실은 바닥에 쌓이고, "실 감기"(W)로 다시
  실뭉치로 감아야 다음 단에 쓸 수 있어요.
- **실 교체**: 실뭉치를 다 썼으면 "실 교체"를 눌러 실 창고에서 새 색을
  골라주세요. 그 시점부터 뜬 단은 실제로 그 색으로 캐릭터에 반영됩니다
  — 색을 바꿔가며 뜨면 완성품에도 그대로 줄무늬로 남아요.
- **완성 후**: 목표 단수에 도달하면 캐릭터가 완성품을 자랑하고, "입어보기"
  로 직접 둘러줄 수도 있습니다.

## 📋 화면 구성

| 요소 | 뜻 |
| --- | --- |
| 단수 (뜬 단수/총 단수) | 지금까지 뜬 단수와 목표 단수 |
| 볼 수 (쓴 볼 수/보유 볼 수) | 실 교체로 다 쓴 실뭉치 수 / 갖고 있는 실뭉치 수(선택 입력) |
| 진행 바 | 목표 대비 진행률 |

## 💡 왜 만들었나요?

뜨개질하다 단수를 놓치는 게 싫어서 만든 개인 프로젝트입니다. 그냥
숫자만 세는 카운터 앱이 아니라, 실이 늘고 줄고 다시 감기는 과정
전체가 하나의 캐릭터 애니메이션으로 이어지도록 만들었어요.

## ⚙️ 로컬에서 실행하기

ES 모듈을 쓰기 때문에 `index.html`을 그냥 더블클릭하면 열리지
않습니다. 로컬 서버가 필요해요.

```
python3 serve.py
```

그다음 브라우저에서 `http://localhost:8000`을 엽니다. `serve.py`는
응답에 `Cache-Control: no-store`를 붙이는 것만 다른 `http.server`의
얇은 래퍼입니다 — 파일을 고칠 때마다 브라우저가 옛 버전을 캐시에서
꺼내 써서 안 바뀐 것처럼 보이는 문제를 막아줍니다.

## 🗂️ 코드 구조 (기여/수정 시 참고)

```
src/pixel.js     픽셀 원시 도구 (격자, 직선, 캔버스 출력)
src/sprites.js   스프라이트 데이터와 생성기. 그림만 들어갑니다
src/states.js    상태 표. 타이밍과 전이만 들어갑니다
src/engine.js    모델 + 상태 기계 + 자세별 레이어 조립
src/stash.js     실 창고 색상 목록
src/main.js      DOM 연결
```

분리 기준은 **수정 이유**입니다. 그림이 마음에 안 들면 `sprites.js`,
타이밍이 어색하면 `states.js`, 규칙이 틀렸으면 `engine.js`만 봅니다.

핵심 규칙: **실 총량은 보존됩니다** — `knitLength + pile + ball`이
교체 시점 사이에서는 항상 일정합니다 (실 교체 시에는 새 실뭉치가
열리는 거라 `ball`이 다시 채워집니다).

- 뜨기: 실뭉치 → 뜨개감
- 풀기: 뜨개감 → 바닥
- 감기: 바닥 → 실뭉치

새 상태를 추가할 땐 `states.js`의 `STATES`에 항목을 추가하고,
`engine.js`의 `POSES`에 같은 이름의 자세 함수를 만든 뒤, 필요한
스프라이트를 `sprites.js`에 추가하면 됩니다.

<summary>🎬 픽셀 애니메이션 작업하면서 지킨 것 (펼치기)</summary>

- **회전은 축을 고정해야 합니다.** 축이 같이 움직이면 각도가 아니라
  위치가 바뀌어서 물체가 미끄러집니다.
- **회전은 양 끝이 반대로 움직입니다.** 한쪽이 내려가면 반대쪽은
  올라가야 합니다.
- **프레임마다 모양이 깨지는 건 입체 정보입니다.** 모양을 유지하려고
  고정 스프라이트로 빼면 그 물체만 화면에 납작하게 붙습니다.
- **32px에서 1px 단색 선은 어느 배경에서든 약합니다.** 밝은 심에
  어두운 테두리를 둘러야 밝은 배경과 어두운 몸통 양쪽에서 살아남습니다.
- **되감기와 되돌리기는 다릅니다.** 예비 동작 0.6초가 버그와 의도를
  가릅니다.
- **이 캐릭터는 입보다 눈과 귀로 표현합니다.** 큰 눈 + 무표정의 대비가
  매력이라 입꼬리를 올리면 오히려 약해집니다.
